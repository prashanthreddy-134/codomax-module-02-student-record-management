CODOMAX MODULE 02 PACKAGE
1. student_record_system/ - runnable Student Record Management System
2. learning_notes/Module_02_Learning_Notes.md - learning notes (open in Google Docs or Notion)
3. LinkedIn_Module_02_Post.txt - draft LinkedIn post

Start:
- Extract the ZIP.
- Open a terminal in student_record_system.
- Run: python main.py
- For JSON: python main.py --format json
- Tests: python -m unittest discover -s tests -v

Before submitting, run the app and tests yourself, add your own screenshots, and push the project folder to a GitHub repository you own. The LinkedIn post is a draft; publish it after completing the work.
